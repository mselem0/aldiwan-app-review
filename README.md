# Aldiwan App Review

لوحة عربية لمتابعة ملاحظات تطبيق الديوان من 11–12 أكتوبر 2026.

- سحب وإفلات بين حالات المتابعة.
- بحث وتصنيف وتحديد المسؤول والأولوية ونتائج الاختبار.
- حفظ التقدم محليًا في المتصفح مع تصدير واستيراد JSON.
- مراجع الشات والمرفقات المتاحة مدمجة في الصفحة.

## الاستخدام

افتح الموقع: https://mselem0.github.io/aldiwan-app-review/

التقدم محفوظ على نفس المتصفح والجهاز، ولا تتم مشاركته بين المستخدمين. استخدم التصدير لنقل التقدم أو حفظ نسخة احتياطية. المراجع الصوتية مرفقة ولم يتم تفريغها.

## التشغيل المحلي

افتح index.html في المتصفح. لا يحتاج إلى تثبيت أو خدمات خارجية.

## تجربة المراجعة

- عرض كروت أو لوحة سحب، مع البحث بالأرقام العربية والإنجليزية والفلاتر.
- فتح الصور في عارض كامل مع التكبير والتحريك والتنزيل.
- نافذة مراجعة بأزرار إغلاق ثابتة ودعم Escape والضغط خارج النافذة.
- حفظ تلقائي، والتنقل بين السابق والتالي، وزر «تمت المراجعة والتالي».
- حذف قابل للاسترجاع من المحذوفات، وتراجع عن تغيير الحالة.
- دعم الموبايل بفلاتر قابلة للطي وتبويبين للتفاصيل والمرفقات.

يحافظ الإصدار الحالي على مفتاح التخزين وصيغة ملفات التقدم من الإصدار السابق. يستخدم خط IBM Plex Sans Arabic من Google Fonts.
